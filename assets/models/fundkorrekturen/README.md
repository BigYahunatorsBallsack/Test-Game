# Überarbeitete Fundmodelle

Das [GLB-Paket](DuneBaron_Fundkorrekturen.zip) enthält neue Modelle für die **24 dokumentierten Formabweichungen** sowie fünf Entwürfe für ältere Dünenmeer-Funde, deren sichtbare Geometrie beim ersten Vergleich offen blieb. Der [Bildvergleich](vergleich.jpg) zeigt links die vorhandenen Icons und rechts die neu exportierten Modelle.

Die Meshes verwenden eingebettete Vertexfarben. Jedes Modell hat seine vorhandene Fund-ID als Objektnamen, einen Pivot mittig an der Unterkante und eine größte Ausdehnung von 2 Studs. In [manifest.json](manifest.json) stehen der Icon-Pfad, die zugehörige GLB, die Maße und der Zielpfad im Modellkatalog.

Alle 29 GLBs wurden wieder eingelesen und in Studio unter `ServerStorage.DuneBaronFindRevisionsPreview` mit ihren bisherigen Atlas-Ausschnitten aufgebaut. Diese `EditableMesh`-Vorschau gilt für die laufende Studio-Sitzung. Die dauerhaften Quelldateien stehen im Paket für den Studio-Import. [Roblox 3D Importer](https://create.roblox.com/docs/studio/importer)
