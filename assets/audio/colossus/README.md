# Klänge für das Koloss-Event

[Hörprobe](koloss_hoerprobe.wav) · [Roblox-Importpaket](DuneBaron_Colossus_SFX.zip)

| Moment | Klang |
| --- | --- |
| Grabung geöffnet | Kurze Windböe und zwei helle Signaltöne |
| Abschnitt freigelegt | Tiefer Steinimpuls mit herabrieselndem Sand |
| Koloss freigelegt | Warme tiefe Töne und ein heller Abschluss am Brustrelief |

Die [Zuordnung](cue_sheet.json) nennt die drei WAVs und Startzeiten in der Hörprobe. Nach dem Import kann Claude die vergebenen Audio-IDs den bestätigten Eventmomenten zuordnen. Die WAVs sind Mono-PCM mit 48 kHz und 16 Bit. [Roblox-Audioimport](https://create.roblox.com/docs/audio/assets)

[build_colossus_audio.py](../build_colossus_audio.py) erstellt die drei Töne und die Hörprobe.
